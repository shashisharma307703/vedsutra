AUTHENTICATION FLOWS
================================================================================

LOCAL LOGIN FLOW:
  1. User sends username/password to POST /auth/login
  2. Credentials validated against database
  3. Password verified using bcrypt
  4. JWT tokens generated (access + refresh)
  5. Refresh session created in database
  6. Tokens returned to client

OIDC (KEYCLOAK) LOGIN FLOW:
  1. User navigates to GET /auth/sso
  2. Secure state parameter generated
  3. Redirect URL built from discovery document
  4. User redirected to Keycloak
  5. User logs in at Keycloak
  6. Keycloak redirects to GET /sso/callback?code=...&state=...
  7. Code exchanged for tokens from Keycloak
  8. User info fetched from Keycloak
  9. User JIT provisioned in local database
  10. Local JWT tokens generated
  11. Refresh session created
  12. Client redirected with tokens

TOKEN REFRESH FLOW:
  1. Client sends refresh token to POST /auth/refresh
  2. Token validated and session retrieved
  3. If refresh_token_rotation enabled:
     - Old session revoked
     - New refresh token generated
     - New session created
  4. New access token generated
  5. New tokens returned to client

DATABASE SCHEMA
================================================================================

TABLE: auth_sessions
├─ id (BIGINT): Primary key
├─ user_id (BIGINT): Foreign key to users
├─ tenant_id (BIGINT): Foreign key to tenants
├─ refresh_token_hash (VARCHAR): SHA256 hash of refresh token
├─ expires_at (TIMESTAMP): Token expiration
├─ created_at (TIMESTAMP): Session creation
├─ last_used_at (TIMESTAMP): Last token use
├─ ip_address (VARCHAR): Client IP
├─ user_agent (TEXT): Client user agent
├─ is_revoked (BOOLEAN): Revocation status
└─ Indexes: user_id, tenant_id, refresh_token_hash, expires_at

TABLE: auth_providers
├─ id (BIGINT): Primary key
├─ tenant_id (BIGINT): Foreign key to tenants
├─ provider_type (VARCHAR): keycloak, local, google, microsoft, ldap
├─ config (JSONB): Provider configuration (discovery_url, client_id, etc.)
├─ is_active (BOOLEAN): Active status
├─ created_at (TIMESTAMP): Creation timestamp
├─ updated_at (TIMESTAMP): Update timestamp
└─ Unique: (tenant_id, provider_type)

TABLE: oidc_discovery_cache
├─ id (BIGINT): Primary key
├─ issuer (VARCHAR): OIDC issuer URL
├─ discovery_doc (JSONB): Full discovery document
├─ cached_at (TIMESTAMP): Cache time
├─ expires_at (TIMESTAMP): Cache expiration
└─ Indexes: issuer, expires_at

================================================================================
HTTP ENDPOINTS
================================================================================

PUBLIC ENDPOINTS (no auth required):
├─ POST /auth/login
│  └─ Local username/password login
├─ GET /auth/sso
│  └─ Initiate OIDC/Keycloak login (redirects to provider)
├─ GET /sso/callback
│  └─ OIDC provider callback (handles code exchange)
└─ POST /auth/refresh
   └─ Refresh access token using refresh token

PROTECTED ENDPOINTS (auth required):
├─ GET /auth/me
│  └─ Get current user information
└─ POST /auth/logout
   └─ Logout (revoke all user sessions)
